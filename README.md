# be-standard

This repository is a learning project for building a production-ready Go backend from first principles.

Start with the [backend learning and implementation roadmap](BACKEND_LEARNING_ROADMAP.md). It contains:

- a seven-day preparation track for a frontend engineer;
- the target architecture and technology choices;
- an incremental implementation plan from domain discovery through one production service, database recovery, messaging, distributed systems, cloud/platform operations, maintenance, and a capstone;
- the backend concepts, production practices, and common failure modes to learn;
- a production-readiness checklist and curated primary references.

For later review, use the [phase-by-phase key-concept refresher](study-materials/backend-phase-key-concepts.md).
It summarizes the mental models, common failure modes, and self-check questions for implementation Phases 0-26 without duplicating their deliverables.

Status: planning only. No application architecture or runtime behavior has been implemented yet.
